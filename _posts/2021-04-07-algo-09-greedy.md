## 🇰🇷 그리디가 통하는 조건
매 순간의 최선 선택이 전체 최선으로 이어진다는 **근거가 있을 때만** 씁니다. 근거 없이 쓰면 반례에 걸립니다.

## 동전 0 (백준 11047)
동전 단위가 **서로 배수 관계**라서 큰 동전부터 최대한 쓰는 것이 최선입니다. (배수 관계가 아니면 DP가 필요합니다.)
```python
count = 0
for c in reversed(coins):
    count += k // c
    k %= c
print(count)
```

## 회의실 배정 (백준 1931)
회의를 **끝나는 시각 순**(같으면 시작 시각 순)으로 정렬하고, 시작이 직전 회의 끝 이후인 것을 고릅니다. 일찍 끝나는 회의를 고를수록 남는 시간이 최대가 됩니다.
```python
meetings.sort(key=lambda x: (x[1], x[0]))
last = count = 0
for s, e in meetings:
    if s >= last:
        count += 1
        last = e
print(count)
```
정렬 키에서 `x[0]`을 같이 넣는 이유는 **시작과 끝이 같은 회의**(길이 0)가 있기 때문입니다.

## 주유소 (백준 13305)
지금까지 지나온 도시 중 **가장 싼 기름값**으로 다음 구간을 갈 만큼 미리 사는 것이 최선입니다.
```python
price, total = city[0], 0
for i in range(len(road)):
    price = min(price, city[i])
    total += price * road[i]
print(total)
```

## 배운 점
- 회의실 문제의 첫 시도(저장소에 주석으로 남아 있음)는 모든 회의를 시작점으로 삼아 겹치지 않는 회의를 세는 O(n²) 방식이었습니다. "끝나는 시각으로 정렬"이라는 기준 하나로 한 번만 훑는 방식으로 바꿨습니다.
- 정렬 기준 선택이 풀이의 거의 전부인 경우가 많습니다.

## 🇺🇸 Summary
Greedy works only when local optimal choices provably lead to the global optimum: coin change with divisible denominations, interval scheduling sorted by end time (tie-break by start), and "buy fuel at the cheapest price so far". The sort key is often the whole solution.
