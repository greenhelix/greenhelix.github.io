## 실패율 — 분모를 같이 갱신
스테이지 i의 실패율은 `i에 머문 사람 / i에 도달한 사람`입니다. 도달한 사람 수는 처음엔 전체이고, 스테이지를 지날 때마다 **머문 사람만큼 줄어듭니다.**
```python
def solution(N, stages):
    p, res = len(stages), []
    for i in range(1, N + 1):
        t = stages.count(i)
        res.append((i, t / p if p else 0))
        p -= t
    return [i for i, _ in sorted(res, key=lambda x: (-x[1], x[0]))]
```
`N=5`, `[2,1,2,6,2,4,3,3]`이면 `[3,4,2,1,5]`입니다. `p`가 0이 되는 경우(아무도 도달하지 못한 스테이지)를 막지 않으면 0으로 나누기 오류가 납니다. 처음에는 이 계산을 복잡하게 짰는데, 분모를 하나의 변수로 줄여 나가는 방식이 더 짧았습니다.

## 방금그곡 — 입력을 정규화
`C#`처럼 두 글자인 음을 한 글자(`c`)로 바꿔 두면, 이후 모든 비교가 **문자열 부분 검색**으로 단순해집니다. 재생 시간만큼 멜로디를 반복해 이어 붙인 뒤 기억한 멜로디가 그 안에 있는지 `in`으로 확인합니다. 길이가 같은 후보가 여러 개면 먼저 입력된 것이 우선이라, 정렬 키를 `(-재생시간, 입력순서)`로 둡니다.
```python
def code_change(m):
    for a, b in (("A#", "a"), ("C#", "c"), ("D#", "d"), ("F#", "f"), ("G#", "g")):
        m = m.replace(a, b)
    return m
```

## 캐시 — LRU 시뮬레이션
캐시에 있으면 1(그리고 최근 사용으로 이동), 없으면 5의 시간이 듭니다. 대소문자는 구분하지 않고, 캐시 크기가 0이면 전부 5입니다. 리스트에서 꺼내 맨 뒤로 보내는 방식으로 LRU를 흉내 냈습니다. 크기 0을 먼저 처리하지 않으면 틀립니다.

## 괄호 회전하기 — 시간 초과에서 개선까지
문자열을 한 칸씩 회전시켜 올바른 괄호인 경우를 셉니다. 첫 풀이는 예제는 통과했지만 **제출 시 시간 초과**였다고 코드 주석에 남아 있습니다. 저장소에는 판정을 별도 함수로 분리한 두 번째 버전이 같이 있습니다. 아래는 이를 다시 정리한 코드로, 스택에서 꺼낸 짝이 맞지 않으면 **즉시 False**를 반환합니다.
```python
from collections import deque

def check(s):
    st = []
    pair = {')': '(', '}': '{', ']': '['}
    for ch in s:
        if ch in '({[':
            st.append(ch)
        elif not st or st.pop() != pair[ch]:
            return False
    return not st

def solution(s):
    d = deque(s)
    cnt = 0
    for _ in range(len(s)):
        cnt += check(d)
        d.rotate(-1)
    return cnt
```
`"[](){}"`이면 3입니다. 복잡도는 O(n²)입니다.

## 배운 점
- 입력을 먼저 **정규화**(`C#`→`c`)하면 이후 로직이 단순해집니다.
- 판정 로직을 함수로 분리하고 **조기 종료**를 넣으면 코드가 단순해지고 불필요한 순회가 줄어듭니다.

## 🇺🇸 Summary
Simulation-style Kakao problems: failure rate (shrink the denominator as stages pass, guard zero), "just the song" (normalize two-character sharps to single characters, then substring search), LRU cache (handle size 0 first), and bracket rotation (extract the validity check and return early).
