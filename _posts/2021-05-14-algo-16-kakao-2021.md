## 메뉴 리뉴얼 — 조합 + Counter
각 주문에서 코스 길이 k짜리 **조합**을 전부 뽑아 개수를 세고, 최댓값이 2 이상인 조합이 정답입니다. 정렬해서 조합을 만드는 것이 중요합니다. `AC`와 `CA`가 같은 메뉴이기 때문입니다.
```python
from itertools import combinations as comb
from collections import Counter

def solution(orders, course):
    answer = []
    for k in course:
        c = Counter()
        for o in orders:
            c.update(''.join(x) for x in comb(sorted(o), k))
        if c:
            m = max(c.values())
            if m > 1:
                answer += [x for x, v in c.items() if v == m]
    return sorted(answer)
```
예제(`["ABCFG","AC","CDE","ACDE","BCFG","ACDEH"]`, `[2,3,4]`)는 `["AC","ACDE","BCFG","CDE"]`로 확인했습니다. 처음 풀이는 모든 조합 후보에 대해 모든 주문을 훑어서 느렸고, Counter로 바꾸면 주문에서 나오는 조합만 세게 됩니다.

## 후보키 — 최소성 검사 단순화
컬럼 조합을 **작은 것부터** 보면서 유일성을 만족하면 후보키로 추가합니다. 이미 후보키의 부분집합을 포함하면 최소성에 어긋나므로 건너뜁니다. 집합 비교 이중 반복문 대신 이 순서가 더 간단했습니다.
```python
from itertools import combinations

def solution(relation):
    n, keys = len(relation[0]), []
    for r in range(1, n + 1):
        for c in combinations(range(n), r):
            if any(set(k) <= set(c) for k in keys):
                continue
            if len({tuple(row[i] for i in c) for row in relation}) == len(relation):
                keys.append(c)
    return len(keys)
```

## 광고 삽입 — 차분 배열과 누적 합
재생 시간이 최대 99:59:59 (약 36만 초)라서 구간을 하나씩 비교하면 시간이 모자랍니다. 그래서 초 단위 배열에 **시작 +1, 끝 −1**을 기록하고 누적 합을 두 번 구합니다. 한 번 누적하면 "각 초의 시청자 수", 두 번 누적하면 "시작부터 그 초까지의 총 시청 시간"이 됩니다. 길이 W짜리 광고 구간의 총 시청 시간은 `S[i] - S[i-W]`로 O(1)에 나옵니다. 이 구간 합을 슬라이딩하며 최댓값을 찾습니다. 전체 O(재생 시간)입니다.

## 합승 택시 요금 — 다익스트라
출발점 s에서 어떤 지점 x까지 **같이 가고**, 거기서 a와 b로 따로 가는 경우의 최소 합입니다. 모든 x에 대해 `dist(s,x) + dist(x,a) + dist(x,b)`의 최솟값을 구합니다. 간선이 양방향이라 `dist(x,a)`는 `dist(a,x)`와 같습니다. 구현은 [다익스트라 글]({% post_url 2021-01-24-algo-07-dijkstra %})과 같은 틀입니다. 저장소의 풀이는 x마다 다익스트라를 3번 부르는 방식이라, **s, a, b에서 각각 한 번씩만** 부르면 3번으로 줄어듭니다.

## 배운 점
- "구간의 합"이 반복해서 나오면 누적 합을 먼저 떠올립니다.
- 같은 다익스트라를 **어디서 몇 번 호출하는가**가 이 문제의 핵심이었습니다.
- 미완성인 풀이도 저장소에 남아 있습니다. 양궁대회는 완전탐색(11개 과녁 조합)의 뼈대만 있습니다.
