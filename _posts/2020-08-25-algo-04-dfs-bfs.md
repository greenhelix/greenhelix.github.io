## 🇰🇷 언제 무엇을 쓰나
| 질문 | 선택 |
|---|---|
| 모든 경우를 따져 개수/가능 여부를 센다 | DFS(재귀) |
| 가장 짧은 단계 수/거리를 구한다 | BFS(큐) |

## DFS: 타깃 넘버 (프로그래머스)
각 숫자에 +/−를 붙여 합이 타깃이 되는 경우의 수. 숫자마다 두 갈래로 갈라지는 재귀입니다.
```python
def solution(numbers, target):
    if not numbers:
        return 1 if target == 0 else 0
    return (solution(numbers[1:], target + numbers[0])
          + solution(numbers[1:], target - numbers[0]))
```

## BFS: 단어 변환 (프로그래머스)
한 글자만 다른 단어끼리 간선으로 보고, 시작 단어에서 목표 단어까지의 **최소 변환 횟수**를 BFS로 구합니다. 큐에 `(단어, 단계)`를 넣어 단계를 함께 들고 다닙니다.
```python
from collections import deque

def solution(begin, target, words):
    diff1 = lambda a, b: sum(x != y for x, y in zip(a, b)) == 1
    near = {w: [x for x in words if diff1(x, w)] for w in words + [begin]}
    q = deque([(begin, 0)])
    seen = {begin}
    while q:
        cur, level = q.popleft()
        for w in near[cur]:
            if w == target:
                return level + 1
            if w not in seen:
                seen.add(w)
                q.append((w, level + 1))
    return 0
```

## 격자에서의 BFS: 미로 탐색(백준 2178), 토마토(백준 7576)
- 상하좌우 이동은 `dx = [1,-1,0,0]`, `dy = [0,0,-1,1]`로 4방향을 반복합니다.
- **방문 표시를 거리 배열에 겸합니다.** 이동할 때 `board[nx][ny] = board[x][y] + 1`로 쓰면 별도 방문 배열이 필요 없고, 도착 칸의 값이 곧 최단 거리입니다.
- 토마토는 **시작점이 여러 개**입니다. 익은 토마토를 전부 먼저 큐에 넣고 한 번에 BFS를 돌립니다.

## 배운 점
- 큐를 리스트 `del queue[0]`로 만들면 O(n)이라 느립니다. `deque.popleft()`를 쓰세요. 미로 탐색 풀이는 리스트 큐를 썼고, 토마토 풀이부터 `deque`를 썼습니다.
- 최단 거리 + "상태가 하나 더 붙는" 문제(벽 부수고 이동하기, 백준 2206)는 `visited[x][y][벽을 부쉈는가]`처럼 **상태를 차원으로 늘려** BFS합니다.

## 🇺🇸 Summary
Use DFS to count or enumerate possibilities (Target Number) and BFS for shortest steps (Word Change, maze, tomatoes). Store distance in the board itself to double as the visited marker; start multi-source BFS from all ripe tomatoes at once; use `deque.popleft()` rather than list deletion; and add an extra state dimension (e.g., "wall already broken") for shortest-path variants.
