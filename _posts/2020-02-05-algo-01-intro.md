## 🇰🇷 이 시리즈는
2020년 2월부터 코딩 공부하며 푼 풀이를 GitHub 저장소(`AlgorithmStudy`)에 쌓아 왔습니다. 약 400개 파일, 대부분 Python이고 Java·C·Kotlin도 있습니다. 풀이를 문제별로 나열하면 읽기 어려워서, **주제별로 묶어 핵심 아이디어만** 다시 정리합니다.

| 출처 | 규모 | 주로 다룬 주제 |
|---|---|---|
| 백준 | 약 160개 | 정렬, 백트래킹, DP, 그리디, BFS/DFS, 최단경로 |
| 코드시그널 | 약 120개 | 입문, DB, Python 챕터 |
| 프로그래머스 | 약 60개 | DFS/BFS, 해시, 힙, 정렬, 카카오 기출 |
| 책 "뇌를 자극하는 알고리즘" | 약 40개 | C로 구현한 큐, 트리, 정렬 |

## 글을 읽는 법
- 날짜는 해당 풀이를 **처음 커밋한 날**입니다. 번호순 = 시간순입니다.
- 각 글은 **아이디어 → 핵심 코드 → 복잡도 → 배운 점** 순서로 씁니다.
- 코드는 디버깅용 `print`를 걷어낸 핵심만 싣습니다. 풀이가 틀렸거나 미완성이면 그렇다고 적습니다.
